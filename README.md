# contact-management-system-java

A console-based Contact Management System built with Java, OOP, and DSA concepts, featuring contact management, searching, sorting, validation, and file-based data persistence.

## Features

- Add new contacts with auto-generated unique Contact IDs
- Display all stored contacts
- Search contacts by name
- Search contacts using exact phone number
- Update existing contact details
- Delete contacts using Contact ID
- Sort contacts alphabetically by name
- Regex-based input validation
- Validate 10-digit phone numbers
- Save contact records to a local text file
- Load previously saved contact records
- Persistent data storage using Java File I/O

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Data Structures & Algorithms (DSA)
- ArrayList
- Java Collections Framework
- Collections.sort()
- BufferedReader
- BufferedWriter
- Scanner
- JDK

## DSA Concepts

This project demonstrates practical implementation of:

- Dynamic data storage using ArrayList
- Searching and string matching
- Alphabetical sorting
- Collections and custom comparators
- Input validation
- File-based data persistence
